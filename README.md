# Simple-Chatbot-Web-Application
A simple Cohere Chatbot application built on Django and Langraph, based on a past information retrieval group project. 

REQUIRES YOU TO HAVE YOUR OWN COHERE API KEY STORED IN A `.env` FILE.

CSS SOURCE: https://www.subframe.com/tips/css-chat-examples

To run the web application, change your directory to `DjangoChatbot` and run the following:

 ```
 python .\manage.py runserver 
 ```

 I have no plans to deploy this, this being a fun little project to familiarize myself with Django and Langgraph.
